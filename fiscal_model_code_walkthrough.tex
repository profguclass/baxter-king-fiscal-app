\begin{abstract}
\noindent This document explains \emph{every} line of \texttt{fiscal\_model.py}
--- the model behind the Streamlit app that replicates and extends Baxter \&
King (1993, \textit{AER}), ``Fiscal Policy in General Equilibrium'' ---
pairing each statement with the exact mathematical object it represents,
cited as \textbf{L}$n$ for line $n$. The current file goes beyond the
paper's baseline model in one respect the app exposes as a first-class
control: \textbf{productive public capital} (the paper's Section VI
extension), with production $Y_t=AK_t^{\theta_K}(K^G_t)^{\theta_G}N_t^{\theta_N}$
and total government purchases split into three pieces --- basic purchases
$G_B$, public investment $I^G$ (which accumulates into $K^G$), and lump-sum
transfers $TR$. Where the code implements a nontrivial derivation (the
log-linearization of the household's Euler equation and labor-leisure
condition with public capital included, and the Blanchard--Kahn/King--
Plosser--Rebelo saddle-path solution via eigendecomposition), that
derivation is carried out here from the model's first-order conditions,
term by term, so that every coefficient in the code is traceable to an
economic equation rather than merely restated.
\end{abstract}

\section{Module docstring and the model in one page (L1--L53)}

The docstring (L1--L44) states the model compactly:
\begin{align}
u_t &= \log C_t + \theta_L\log L_t, \qquad L_t = 1-N_t \tag{preferences}\\
Y_t &= A\,K_t^{\theta_K}(K^G_t)^{\theta_G}N_t^{\theta_N}, \qquad \theta_K=1-\theta_N \tag{technology}\\
K_{t+1} &= (1-\delta)K_t+I_t, \qquad K^G_{t+1}=(1-\delta)K^G_t+I^G_t \tag{capital accum.}\\
Y_t &= C_t+I_t+G_{B,t}+I^G_t \tag{resource constraint}\\
\tau_t Y_t &= G_{B,t}+I^G_t+TR_t, \qquad \tau_t=\frac{G_{B,t}+I^G_t+TR_t}{Y_t} \tag{government budget}
\end{align}
with two financing rules for a change in total government purchases: both
set $\tau_t$ by the \emph{same} formula above; they differ only in whether
that tax is a genuine wedge on the household's factor income
(\textbf{income\_tax}, the paper's original ``distortionary''/GRH channel)
or a non-distorting poll tax for the same revenue (\textbf{lump\_sum}). Two
solution objects are provided: an exact closed-form \texttt{steady\_state}
(Section~\ref{sec:ss}) and a log-linearized \texttt{simulate\_transition}
(Sections \ref{sec:loglinear}--\ref{sec:transition}). All quantities are
\emph{great ratios} --- shares of output/the time endowment --- so the
model is scale-free (L41--43).

\section{\texttt{\_supply\_side\_impl}: the price system with public capital (L60--L91)}
\label{sec:supply}

\begin{lstlisting}[firstnumber=60]
def _supply_side_impl(theta_N: float, delta: float, r: float, A: float, tau: float,
                       theta_G: float, s_IG: float, distortionary: bool) -> dict:
\end{lstlisting}
\begin{itemize}
\item[\textbf{L60--L61}] Signature: seven primitives (five original plus
$\theta_G$, the public-capital productivity parameter, and $s_{I^G}$, the
public-investment share of output) plus a financing flag, out comes a
dictionary of derived prices/ratios. This function embodies the model's
\emph{intratemporal, labor-independent} block: because production is
constant-returns in $(K,N)$ for any \emph{given} level of public capital
$K^G$, the capital/labor ratio $\kappa=K/N$ is pinned down by the
capital-Euler condition alone, without yet knowing the level of labor
supply $N$ --- that is solved separately in Section~\ref{sec:calib}.
\end{itemize}

\begin{lstlisting}[firstnumber=62]
theta_K = 1.0 - theta_N
wedge = (1.0 - tau) if distortionary else 1.0
if wedge <= 0:
    raise ValueError("Invalid parameters: tax wedge (1-tau) must be positive under Income Tax financing.")

kappa = ((wedge * theta_K * A) / (r + delta)) ** (1.0 / (1.0 - theta_K))
alpha = A * kappa ** theta_K  # will be rescaled by KG^theta_G below
KG = 0.0
\end{lstlisting}
\begin{itemize}
\item[\textbf{L62}] $\theta_K=1-\theta_N$, capital's Cobb--Douglas share.
\item[\textbf{L63}] The tax wedge on the household's factor income:
$\omega\equiv(1-\tau)$ under \texttt{income\_tax} financing, $\omega\equiv1$
under \texttt{lump\_sum} financing (the poll tax leaves the marginal
after-tax return to working/saving untouched). This single scalar is
\emph{the} difference between the two financing rules everywhere in the
file --- both set the same $\tau$ (Section~\ref{sec:ss}), but only
\texttt{income\_tax} lets $\tau$ enter here.
\item[\textbf{L64--L65}] Guards against $\omega\le0$ (a tax rate $\ge100\%$
under income-tax financing, which would make after-tax factor income
non-positive).
\item[\textbf{L67}] Solves the household's after-tax capital-Euler
condition for the capital/labor ratio, \emph{ignoring public capital's
contribution to the marginal product for now} (that correction is applied
in the fixed-point loop below when $\theta_G>0$):
\eq{ \omega\,\theta_K\, A\,\kappa^{\theta_K-1} = r+\delta \label{eq:euler-ss0} }
--- the steady-state statement that the after-tax marginal product of
capital equals the required gross return $r+\delta$. Solving for $\kappa$:
$\kappa = \big(\omega\theta_K A/(r+\delta)\big)^{1/(1-\theta_K)}$.
\item[\textbf{L68}] Average product of labor \emph{holding $K^G$ at its
$\theta_G=0$ value}, $\alpha\equiv Y/N = A\kappa^{\theta_K}$ (substitute
$K=\kappa N$ into $Y=AK^{\theta_K}N^{\theta_N}$, i.e.\ the $K^G$-free case,
and divide by $N$); the comment flags that this gets rescaled below.
\item[\textbf{L69}] Initializes $K^G=0$, the value used unless the
fixed-point loop below runs.
\end{itemize}

\begin{lstlisting}[firstnumber=70]
if theta_G > 0 and s_IG > 0:
    alpha_ppN = A * kappa ** theta_K  # Y/N ignoring KG, will multiply by KG^theta_G
    alpha_guess = alpha_ppN
    for _ in range(200):
        KG_ppN = s_IG * alpha_guess / delta  # KG per unit of N
        base = (wedge * theta_K * A * KG_ppN ** theta_G) / (r + delta)
        kappa = base ** (1.0 / (1.0 - theta_K))
        alpha_new = A * kappa ** theta_K * KG_ppN ** theta_G
        if abs(alpha_new - alpha_guess) < 1e-12:
            alpha_guess = alpha_new
            break
        alpha_guess = alpha_new
    alpha = alpha_guess
    KG = s_IG * alpha / delta  # KG per unit of N
\end{lstlisting}
\label{sec:kgfixedpoint}
\begin{itemize}
\item[\textbf{L70}] Only run the (more expensive) fixed-point iteration
when public capital is actually productive ($\theta_G>0$) \emph{and}
present ($s_{I^G}>0$); otherwise $K^G\equiv0$ from L69 and the block below
is skipped entirely, so $\theta_G=0$ collapses this function exactly to
the paper's baseline model with zero extra cost.
\item[\textbf{Why a fixed point is needed.}] With public capital, the
capital-Euler condition \eqref{eq:euler-ss0} generalizes to
\eq{ \omega\,\theta_K\,A\,(K^G/N)^{\theta_G}\,\kappa^{\theta_K-1} = r+\delta, \label{eq:euler-ss-kg}}
but $K^G$ itself is pinned down by its own steady-state accumulation
identity $K^G=I^G/\delta$ (from $K^G_{t+1}=(1-\delta)K^G_t+I^G_t$ at a
steady state), and $I^G=s_{I^G}Y$, and $Y$ depends on $\kappa$ through
\eqref{eq:euler-ss-kg} --- a circular dependency solved by iterating on
$\alpha\equiv Y/N$ until it stops moving. All quantities here are kept
\emph{per unit of $N$} (denoted with a \texttt{\_ppN} suffix) because $N$
itself is not yet known at this stage (Section~\ref{sec:calib} solves for
$N$ only afterward) and the ratio $K^G/N$ is scale-invariant in $N$, so the
iteration is well posed without it.
\item[\textbf{L71--L72}] Initializes the iteration guess $\alpha_{\text{guess}}$
at the $K^G=0$ value of $\alpha$ from L68.
\item[\textbf{L73}] Up to $200$ fixed-point sweeps (in practice this
converges in a handful of iterations for any economically sensible
calibration).
\item[\textbf{L74}] $K^G/N \equiv s_{I^G}\,\alpha_{\text{guess}}/\delta$,
from $K^G=I^G/\delta=s_{I^G}Y/\delta$ divided by $N$.
\item[\textbf{L75}] Recomputes $\kappa$ from \eqref{eq:euler-ss-kg} using
the current $K^G/N$ guess: $\kappa=\big(\omega\theta_K A\,(K^G/N)^{\theta_G}/(r+\delta)\big)^{1/(1-\theta_K)}$.
\item[\textbf{L76}] Recomputes $\alpha_{\text{new}}=A\kappa^{\theta_K}(K^G/N)^{\theta_G}$,
the full public-capital-augmented average product of labor.
\item[\textbf{L77--L79}] Stops early once the guess has converged to
$10^{-12}$; otherwise updates the guess and continues.
\item[\textbf{L80--L81}] After the loop, $\alpha$ and $K^G/N$ (denoted
\texttt{KG} in the code, a slight abuse --- it is really $K^G$ per unit of
$N$ at this point, made a true level once multiplied by $N$ in
\texttt{steady\_state}, Section~\ref{sec:ss}) are finalized at their
fixed-point values.
\end{itemize}

\begin{lstlisting}[firstnumber=88]
w = theta_N * alpha
q = wedge * theta_K * alpha / kappa
s_I = delta * kappa / alpha
return dict(theta_K=theta_K, kappa=kappa, alpha=alpha, w=w, q=q, s_I=s_I, KG=KG, wedge=wedge)
\end{lstlisting}
\begin{itemize}
\item[\textbf{L88}] The pre-tax real wage, equal to the marginal product of
labor: $w=\theta_N\alpha=\theta_N\,Y/N$ (unaffected in form by public
capital, since $K^G$ enters $Y$ multiplicatively and Cobb--Douglas shares
are unchanged).
\item[\textbf{L89}] The after-tax rental rate on capital,
$q=\omega\theta_K\alpha/\kappa$. Since $\alpha/\kappa=Y/K$, this is
$q=\omega\theta_K Y/K=\omega\cdot\text{MPK}$ --- and by construction
(because $\kappa$ was solved from \eqref{eq:euler-ss-kg}), $q\equiv
r+\delta$ exactly.
\item[\textbf{L90}] The steady-state investment share of output,
$s_I\equiv I/Y=\delta K/Y=\delta\kappa/\alpha$, using $I=\delta K$ at a
steady state.
\item[\textbf{L91}] Packages eight derived quantities, including the
\texttt{wedge} $\omega$ itself (reused by every caller so the financing
distinction never has to be recomputed) and \texttt{KG} (public capital
per unit of $N$, possibly still $0$).
\end{itemize}

\begin{lstlisting}[firstnumber=135]
def calibrate_theta_L(theta_N: float, delta: float, r: float, A: float, theta_G: float,
                       s_GB: float, s_IG: float, s_TR: float, distortionary: bool,
                       N_target: float) -> float:
    tau = s_GB + s_IG + s_TR
    supply = _supply_side_impl(theta_N, delta, r, A, tau, theta_G, s_IG, distortionary)
    s_GR = s_GB + s_IG
    s_C = 1.0 - supply["s_I"] - s_GR
    if s_C <= 0:
        raise ValueError("Government share too large: steady-state consumption share <= 0.")
    N = N_target
    theta_L = supply["wedge"] * theta_N * (1.0 - N) / (s_C * N)
    if theta_L <= 0:
        raise ValueError("Implied theta_L <= 0; adjust N_target or the tax/spending settings.")
    return theta_L
\end{lstlisting}
\label{sec:calib}
\begin{itemize}
\item[\textbf{L135--L137}] Signature: given the technology/policy
primitives (now including $\theta_G$ and the three-way composition
$s_{GB},s_{IG},s_{TR}$) plus a target labor supply $\bar N\equiv$
\texttt{N\_target}, returns the leisure-preference weight $\theta_L$ that
makes steady-state labor supply equal $\bar N$.
\item[\textbf{L140}] The tax rate is \emph{defined} as total government
purchases over output, $\tau=s_{GB}+s_{IG}+s_{TR}$ --- this is the
government-budget identity from the docstring, holding identically
regardless of financing rule.
\item[\textbf{L141}] Calls Section~\ref{sec:supply}'s function to get
$s_I$ and $\omega$ (\texttt{wedge}).
\item[\textbf{L142}] $s_{GR}\equiv s_{GB}+s_{IG}$, the \emph{resource-using}
share of government purchases --- deliberately excluding $s_{TR}$, since
transfers are a pure redistribution that does not appear in the economy's
resource constraint (they cancel out of the household budget, as
explained in Section~\ref{sec:policybudget}).
\item[\textbf{L143}] The consumption share, $s_C=1-s_I-s_{GR}$, from the
resource constraint $1=s_C+s_I+s_{GR}$ (dividing $Y=C+I+G_B+I^G$ through
by $Y$; note $TR$ is absent).
\item[\textbf{L144--L145}] Guards against $s_C\le0$.
\item[\textbf{L146}] Aliases $N\leftarrow$ \texttt{N\_target}.
\item[\textbf{L147}] The calibration formula. It comes from the
labor-leisure first-order condition
\eq{ \theta_L\,\frac{C}{L} = \omega\,w \label{eq:foc-labor} }
(the marginal rate of substitution between consumption and leisure equals
the after-tax wage --- $\omega$ generalizes the paper's $(1-\tau)$ to also
cover the lump-sum case, where $\omega=1$), solved for $\theta_L$ using
$w=\theta_N\alpha$, $C=s_C Y$, $\alpha=Y/N$, and $L=1-N$:
\eq{ \theta_L = \frac{\omega\,w\,L}{C} = \frac{\omega\,\theta_N(1-N)}{s_C N}. }
This is exactly L147. This step \emph{calibrates a preference parameter}
to hit a labor-supply target --- it does not yet compute $Y,K,$ or any
level; those come from \texttt{steady\_state} below using this $\theta_L$
as an input.
\item[\textbf{L148--L149}] Guards against a non-positive $\theta_L$.
\end{itemize}

\begin{lstlisting}[firstnumber=153]
def steady_state(theta_N: float, delta: float, r: float, A: float, theta_G: float,
                  s_GB: float, s_IG: float, s_TR: float, distortionary: bool,
                  theta_L: float) -> SteadyState:
    tau = s_GB + s_IG + s_TR
    s_G = tau
    supply = _supply_side_impl(theta_N, delta, r, A, tau, theta_G, s_IG, distortionary)
    s_I = supply["s_I"]
    s_GR = s_GB + s_IG
    s_C = 1.0 - s_I - s_GR
    if s_C <= 0:
        raise ValueError("Government share too large: steady-state consumption share <= 0.")
\end{lstlisting}
\begin{itemize}
\item[\textbf{L153--L155}] Signature: the same primitives plus $\theta_L$
(now taken as \emph{given}, not calibrated), returning a full
\texttt{SteadyState}.
\item[\textbf{L158--L165}] Re-derives $\tau,s_G,s_I,s_{GR},s_C$ exactly as
in Section~\ref{sec:calib} (this function is called both directly and,
with the just-calibrated $\theta_L$, immediately after
\texttt{calibrate\_theta\_L} inside \texttt{run\_experiment}).
\end{itemize}

\begin{lstlisting}[firstnumber=167]
wedge = supply["wedge"]
N = wedge * theta_N / (theta_L * s_C + wedge * theta_N)
if not (0 < N < 1):
    raise ValueError(f"Implied labor supply N={N:.3f} is outside (0,1).")

\end{lstlisting}
\begin{itemize}
\item[\textbf{L168}] Solves the same FOC \eqref{eq:foc-labor} for $N$
directly, treating $\theta_L$ as known. From
$\theta_L s_C N=\omega\theta_N(1-N)$, collecting $N$ terms:
\eq{ N\big[\theta_L s_C+\omega\theta_N\big]=\omega\theta_N

This is the algebraic inverse of L147: plugging L147's $\theta_L$ back
into this formula returns exactly $N=$\texttt{N\_target}, which is
precisely what makes \texttt{calibrate\_theta\_L} a correct calibration
(verified numerically by \texttt{test\_model.py}'s ``check N == N\_target''
line).
\item[\textbf{L169--L170}] Guards against an economically infeasible labor
supply outside $(0,1)$.
\item[\textbf{L171}] $L=1-N$, steady-state leisure.
\end{itemize}

\begin{lstlisting}[firstnumber=192]
def steady_state_for_policy(theta_N: float, delta: float, r: float, A: float, theta_G: float,
                             s_G_total: float, f_GB: float, f_IG: float, f_TR: float,
                             theta_L: float, distortionary: bool) -> SteadyState:
    s_GB, s_IG, s_TR = s_G_total * f_GB, s_G_total * f_IG, s_G_total * f_TR
    return steady_state(theta_N, delta, r, A, theta_G, s_GB, s_IG, s_TR, distortionary, theta_L)
\end{lstlisting}
\label{sec:policybudget}
\begin{itemize}
\item[\textbf{L192--L194}] Signature: instead of taking the three
composition levels $(s_{GB},s_{IG},s_{TR})$ directly, this convenience
wrapper takes a \emph{total} government-purchases ratio $s_{G,\text{total}}$
and fixed \emph{composition fractions} $f_{GB},f_{IG},f_{TR}$ (summing to
$1$) that describe how that total is split. This is the function the app
calls once for the baseline policy and once for the counterfactual policy,
holding the composition fractions fixed across the two (so a ``ΔG/Y''
experiment changes the \emph{size} of government at a \emph{fixed} mix;
see the box below on why moving \emph{only} the composition or financing
sliders, with ΔG/Y left at 0, does not by itself register as a policy
change under this convention, and how the app's other panels are the
right place to see those effects).
\item[\textbf{L196}] $s_{GB}=s_{G,\text{total}}f_{GB}$, and similarly for
$s_{IG},s_{TR}$ --- splitting the total by the given fractions.
\item[\textbf{L197}] Calls Section~\ref{sec:ss}'s \texttt{steady\_state}
with the resolved composition levels.
\item[\textbf{On the household budget and why $TR$ drops out of the
resource constraint.}] The government budget is $\tau_tY_t=G_{B,t}+I^G_t+TR_t$
(the docstring's identity, re-derived at L158/L140). The household's
budget constraint differs by financing rule:
\eq{
\text{income\_tax:}\quad C_t+I_t=(1-\tau_t)(w_tN_t+r_tK_t)+TR_t
\qquad
\text{lump\_sum:}\quad C_t+I_t=w_tN_t+r_tK_t-\tau_tY_t+TR_t.
}
Combined with $w_tN_t+r_tK_t=Y_t$ (factor payments exhaust output under
constant returns) and the government budget identity, both cases reduce
\emph{in the aggregate} to $Y_t=C_t+I_t+G_{B,t}+I^G_t$ --- transfers are
received by the household but exactly offset by the (larger, by the
transfer amount) tax it pays, so they wash out of the resource constraint
even though they matter for household-level after-tax income. This is
why \texttt{steady\_state} (L181) computes $G=G_B+I^G+TR$ for reporting
purposes (\emph{total} government purchases, the policy object the sidebar's
$G/Y$ slider controls) while the resource-constraint-relevant share used
throughout the log-linearization (Section~\ref{sec:loglinear}) is
$s_{GR}=s_{GB}+s_{IG}$, never $s_G$.
\end{itemize}

\begin{notebox}
\textbf{Note on what ``1. Comparative steady states'' does and does not
compare.} \texttt{run\_experiment} (Section~\ref{sec:expsec}) builds
\texttt{ss\_old} and \texttt{ss\_new} by calling
\texttt{steady\_state\_for\_policy} \emph{twice}, varying \emph{only} the
total government-purchases ratio ($s_{G,\text{old}}$ vs.\ $s_{G,\text{new}}$,
i.e.\ the sidebar's ``baseline G/Y'' and ``ΔG/Y'' controls) while every
other argument --- $\theta_N,\delta,r,A,\theta_G$, the composition
fractions $f_{GB},f_{IG},f_{TR}$, the financing rule, and the just-calibrated
$\theta_L$ --- is passed \emph{identically} to both calls. This is a
deliberate modeling choice, not an oversight: it isolates the effect of
\emph{one} policy lever (the size of government purchases) holding every
other structural parameter fixed, which is exactly the paper's ``$\Delta Y/\Delta G$
multiplier'' experiment. It means that if the sidebar's ΔG/Y slider is at
$0$ (so $s_{G,\text{old}}=s_{G,\text{new}}$), \texttt{ss\_old} and
\texttt{ss\_new} are computed from \emph{literally identical} arguments and
are therefore identical --- regardless of what the composition sliders,
$\theta_G$, the financing rule, or $r$ are set to. This is why the app
shows an explicit ``ΔG/Y is set to 0 -- no experiment to show yet'' message
and stops in that case, rather than a comparison table that would trivially
show $0\%$ change in every row. Composition, $\theta_G$, financing, and $r$
absolutely do change the level of both \texttt{ss\_old} and
\texttt{ss\_new} (move any of them and re-render, with ΔG/Y $\ne 0$, to see
both columns of the table shift) --- what they do \emph{not} do, by this
function's design, is create a difference \emph{between} the two columns
unless ΔG/Y is also nonzero, since they are held fixed \emph{across} the
comparison rather than being part of what changes.
\end{notebox}

\section{The log-linear coefficients: derivation and code (L205--L258)}

This is the most involved part of the file. The code's own docstring
(L206--L211) states the three (now four, with public capital) blocks to be
solved without deriving them:
\begin{align}
\hat y_t &= y_k\hat k_t+y_{kg}\hat k^G_t+y_c\hat c_t+y_g\hat g_t &&\text{(static block)}\label{eq:static}\\
\hat k_{t+1} &= \Phi_{kk}\hat k_t+\Phi_{kc}\hat c_t+\Phi_{kg}\hat g_t+\Phi_{k,kg}\hat k^G_t &&\text{(capital accumulation)}\label{eq:capaccum}\\

shown as the algebraic consequence of an economic condition. Public
capital's \emph{own} law of motion is handled separately in
Section~\ref{sec:kghat}, since (as will become clear) it does not depend
on $\hat k_t$ or $\hat c_t$ at all.

\subsection{The static block: output as a function of \texorpdfstring{$\hat k,\hat k^G,\hat c,\hat g$}{k,kG,c,g} (L220--L235)}

\textbf{Derivation.} Log-linearize the production function
$Y_t=AK_t^{\theta_K}(K^G_t)^{\theta_G}N_t^{\theta_N}$:
\eq{ \hat y_t = \theta_K\hat k_t+\theta_G\hat k^G_t+\theta_N\hat n_t. \label{eq:prod-loglin} }
This is the only change to \eqref{eq:prod-loglin} relative to the
paper's baseline model: an extra $\theta_G\hat k^G_t$ term, additive and
independent of everything else, since $K^G$ enters the production function
multiplicatively just like $K$. Log-linearize the labor-leisure FOC
\eqref{eq:foc-labor}: writing it as $\theta_L C_t=\omega_t\theta_N
Y_t(1-N_t)/N_t$, taking logs and differentiating, using
$d\log(1-N_t)=-\frac{N}{L}\hat n_t$ (since $L+N=1$),
\eq{ \hat c_t = \hat\omega_t+\hat y_t-\left(1+\frac{N}{L}\right)\hat n_t
             = \hat\omega_t+\hat y_t-\frac{\hat n_t}{L}. \label{eq:foc-loglin}}
Note that $K^G$ does \emph{not} enter \eqref{eq:foc-loglin} directly ---
it only affects $\hat n_t$ indirectly through $\hat y_t$ in
\eqref{eq:prod-loglin} above.

\textbf{Case \texttt{lump\_sum} ($\omega\equiv1$ always, $\hat\omega_t\equiv0$).}
Solving \eqref{eq:foc-loglin} for $\hat n_t$: $\hat n_t=L(\hat y_t-\hat c_t)$.
Substituting into \eqref{eq:prod-loglin}:
\eq{ \hat y_t=\theta_K\hat k_t+\theta_G\hat k^G_t+\theta_N L(\hat y_t-\hat c_t)
     \ \Longrightarrow\ \hat y_t\underbrace{(1-\theta_N L)}_{\displaystyle D}
       = \theta_K\hat k_t+\theta_G\hat k^G_t-\theta_N L\,\hat c_t, }
\eq{ \Longrightarrow\quad y_k=\frac{\theta_K}{D}, \quad y_{kg}=\frac{\theta_G}{D}, \quad y_c=-\frac{\theta_N L}{D}, \quad y_g=0. \label{eq:static-lump}}

\begin{lstlisting}[firstnumber=220]
D = 1.0 - theta_N * L
if ss.distortionary:
    Dp = D - theta_N * L * tau / (1.0 - tau)
    y_k = theta_K / Dp
    y_kg = theta_G / Dp
    y_c = -theta_N * L / Dp
    y_g = -theta_N * L * tau / ((1.0 - tau) * Dp)
    tax_wedge = tau / (1.0 - tau)
else:
    y_k = theta_K / D
    y_kg = theta_G / D
    y_c = -theta_N * L / D
    y_g = 0.0
    tax_wedge = 0.0
\end{lstlisting}
\begin{itemize}
\item[\textbf{L220}] $D\equiv1-\theta_N L$, the denominator in
\eqref{eq:static-lump}.
\item[\textbf{L230--L234}] Exactly implements \eqref{eq:static-lump} for
\texttt{ss.distortionary=False}: no $\hat g_t$ term because $g$ never
enters the lump-sum labor-leisure FOC directly (the tax rate is a poll
tax, not a function of $G_t/Y_t$ at the margin), and $y_{kg}=\theta_G/D$
appears alongside $y_k=\theta_K/D$ with the identical denominator, since
$\hat k^G_t$ entered \eqref{eq:prod-loglin} exactly like $\hat k_t$ did.
\texttt{tax\_wedge}$=0$ here for reuse below (Section~\ref{sec:euler}).
\end{itemize}

\textbf{Case \texttt{income\_tax} ($\tau_t=$ total government purchases$/Y_t$
always, $\omega_t=1-\tau_t$).} Now $\hat\omega_t\neq0$. Differentiating
$\tau_tY_t=G_t$ directly (where $G_t$ is \emph{total} government purchases,
product rule, at steady-state levels):
\eq{ d\tau_t\cdot Y+\tau\,dY_t = dG_t \ \Longrightarrow\ d\tau_t=\tau(\hat g_t-\hat y_t)
     \ \Longrightarrow\ \hat\omega_t=\frac{-d\tau_t}{1-\tau}=\frac{\tau}{1-\tau}(\hat y_t-\hat g_t).
     \label{eq:tauhat} }
(Here $\hat g_t$ denotes the log-deviation of \emph{total} government
purchases $G_t$, the quantity the app's ``ΔG/Y'' experiments move; the
code's \texttt{g\_path} always represents this total, with the composition
fractions $f_{GB},f_{IG},f_{TR}$ held fixed across the experiment ---
Section~\ref{sec:transition} confirms this is exactly how \texttt{g\_full}
is used.) Substituting into \eqref{eq:foc-loglin} and solving for $\hat n_t$:
\eq{ \hat n_t = L\left[\frac{\hat y_t}{1-\tau}-\hat c_t-\frac{\tau}{1-\tau}\hat g_t\right]. \label{eq:n-distortionary} }
This is exactly the formula \texttt{simulate\_transition} uses directly
(Section~\ref{sec:transition}, L375--L378) to recover $\hat n_t$ once
$\hat y_t,\hat c_t,\hat g_t$ are known.

Substituting \eqref{eq:n-distortionary} into \eqref{eq:prod-loglin} and
collecting $\hat y_t$ terms gives the self-consistent static block for the
income-tax case:
\eq{
\hat y_t\left(\underbrace{D-\frac{\theta_N L\tau}{1-\tau}}_{\displaystyle D_p}\right)
   = \theta_K\hat k_t+\theta_G\hat k^G_t-\theta_N L\hat c_t-\frac{\theta_N L\tau}{1-\tau}\hat g_t.
   \label{eq:static-distortionary-correct}
}
\begin{itemize}
\item[\textbf{L222--L223}] Comment recording the derivation (public capital
added, but the sign of the $\tau$ cross-term in $D_p$ is unchanged from
the baseline model, and remains a \emph{minus}, matching
\eqref{eq:static-distortionary-correct}).
\item[\textbf{L224}] $D_p\equiv D-\dfrac{\theta_N L\tau}{1-\tau}$.
\item[\textbf{L225--L228}] $y_k=\theta_K/D_p$, $y_{kg}=\theta_G/D_p$
(the public-capital term inherits the same denominator as $y_k$, exactly
as in the lump-sum case, since $\hat k^G_t$'s coefficient in
\eqref{eq:prod-loglin} was never touched by the tax-wedge substitution),
$y_c=-\theta_N L/D_p$, $y_g=-\theta_N L\tau/[(1-\tau)D_p]$ --- matching
\eqref{eq:static-distortionary-correct} term for term.
\item[\textbf{L229}] $\text{tax\_wedge}\equiv\tau/(1-\tau)$, the scalar
multiplying $(\hat y_{t+1}-\hat g_{t+1})$ in \eqref{eq:tauhat} --- reused
in the Euler-equation coefficients (Section~\ref{sec:euler}) and in
\texttt{simulate\_transition}'s $\hat n_t$ formula.
\end{itemize}

\subsection{The Euler equation coefficients (L237--L249)}
\label{sec:euler}

\textbf{Derivation.} The household's after-tax capital-Euler equation is
\eq{ \frac{1}{C_t} = \beta\,\frac{1}{C_{t+1}}\Big[\omega_{t+1}R_{t+1}+1-\delta\Big], \qquad
     R_{t+1}\equiv\theta_K\frac{Y_{t+1}}{K_{t+1}}\ \text{(pre-tax MPK)}. }
Public capital does not enter this condition directly: the household
chooses \emph{private} capital $K_{t+1}$ taking $K^G_{t+1}$ as given (it is
set by government policy, not privately optimized), so $K^G$'s only
influence on the Euler equation is indirect, through its effect on
$\hat R_{t+1}$ via $\hat y_{t+1}$ (which is exactly how it enters below).
At steady state, $1/\beta=\omega R+1-\delta=q+1-\delta$ where $q=\omega R$
is the after-tax rental rate; since $q\equiv r+\delta$
(Section~\ref{sec:supply}), $\beta=1/(1+r)$. Write
$X_{t+1}\equiv\omega_{t+1}R_{t+1}+1-\delta$ (steady state $X=1/\beta$).
Log-linearizing $1/C_t=\beta X_{t+1}/C_{t+1}$:
\eq{ \hat c_t=\hat c_{t+1}-\hat X_{t+1}, \qquad
     \hat X_{t+1} = \underbrace{\beta q}_{\displaystyle\Omega}
     \Big[\hat\omega_{t+1}+\hat R_{t+1}\Big] }
(using $X=1/\beta$, $q/X=\beta q\equiv\Omega$, exactly as in the baseline
derivation). Since $R_t=\theta_K Y_t/K_t$, $\hat R_t=\hat y_t-\hat k_t$;
using the static block \eqref{eq:static}, $\hat y_t-\hat k_t=(y_k-1)\hat
k_t+y_{kg}\hat k^G_t+y_c\hat c_t+y_g\hat g_t$ --- \emph{now carrying a
$y_{kg}\hat k^G_t$ term that was not present in the baseline model}. And
$\hat\omega_{t+1}$ is $0$ (lump-sum) or
$\text{tax\_wedge}\cdot(\hat y_{t+1}-\hat g_{t+1})$ (income tax, equation
\eqref{eq:tauhat}). Substituting both, then $\hat
y_{t+1}=y_k\hat k_{t+1}+y_{kg}\hat k^G_{t+1}+y_c\hat c_{t+1}+y_g\hat
g_{t+1}$ where needed, and collecting coefficients on $\hat k_{t+1},\hat
k^G_{t+1},\hat c_{t+1},\hat g_{t+1}$ in $\hat c_t=\hat c_{t+1}-\hat
X_{t+1}$ gives exactly the four coefficients below.

\begin{lstlisting}[firstnumber=237]
beta = 1.0 / (1.0 + r)
q = r + delta
Omega = beta * q  # = q/(1+r)

ymk_k = y_k - 1.0
ymk_c = y_c
ymk_g = y_g
ymk_kg = y_kg

coef_c = 1.0 - Omega * ymk_c - Omega * tax_wedge * y_c
coef_k = -Omega * ymk_k - Omega * tax_wedge * y_k
coef_g = -Omega * ymk_g + Omega * tax_wedge * (1.0 - y_g)
coef_kg = -Omega * ymk_kg - Omega * tax_wedge * y_kg
\end{lstlisting}
\begin{itemize}
\item[\textbf{L237}] $\beta=1/(1+r)$, the household discount factor implied
by the steady-state Euler equation.
\item[\textbf{L238}] $q=r+\delta$, the after-tax rental rate.
\item[\textbf{L239}] $\Omega\equiv\beta q$, the discounted after-tax
rental rate --- the single scalar multiplying every marginal-product term
below.
\item[\textbf{L241--L244}] The coefficients of $\hat R_t=\hat y_t-\hat
k_t$ in terms of $\hat k_t,\hat k^G_t,\hat c_t,\hat g_t$: subtracting
$\hat k_t$ from the static block only changes the $\hat k_t$ coefficient,
giving \texttt{ymk\_k}$=y_k-1$, \texttt{ymk\_c}$=y_c$,
\texttt{ymk\_g}$=y_g$, and \texttt{ymk\_kg}$=y_{kg}$ (public capital's
coefficient is untouched, since $\hat k_t$ was never part of $y_{kg}$'s
term).
\item[\textbf{L246}] Coefficient on $\hat c_{t+1}$:
$\text{coef}_c=1-\Omega\cdot\text{ymk\_c}-\Omega\cdot\text{tax\_wedge}\cdot y_c$
(unchanged in form from the baseline model; $\hat k^G_{t+1}$ does not
appear here because $y_{kg}$'s term has no $\hat c$-dependence to collect).
\item[\textbf{L247}] Coefficient on $\hat k_{t+1}$:
$\text{coef}_k=-\Omega\cdot\text{ymk\_k}-\Omega\cdot\text{tax\_wedge}\cdot y_k$
(also unchanged in form).
\item[\textbf{L248}] Coefficient on $\hat g_{t+1}$:
$\text{coef}_g=-\Omega\cdot\text{ymk\_g}+\Omega\cdot\text{tax\_wedge}\cdot(1-y_g)$
(unchanged in form).
\item[\textbf{L249}] Coefficient on $\hat k^G_{t+1}$,
$\text{coef}_{kg}=-\Omega\cdot\text{ymk\_kg}-\Omega\cdot\text{tax\_wedge}\cdot
y_{kg}$ --- structurally identical to \texttt{coef\_k}'s formula (both
$\hat k_{t+1}$ and $\hat k^G_{t+1}$ affect the Euler equation \emph{only}
through their effect on $\hat R_{t+1}=\hat y_{t+1}-\hat k_{t+1}$, so their
coefficients share the same $-\Omega(\cdot)-\Omega\cdot\text{tax\_wedge}\cdot(\cdot)$
template), except there is no ``$-1$'' term analogous to \texttt{ymk\_k}
since $\hat k^G_{t+1}$ does not appear \emph{subtracted} anywhere the way
$\hat k_{t+1}$ does in $\hat R_{t+1}=\hat y_{t+1}-\hat k_{t+1}$ --- public
capital only ever enters through $y_{kg}\hat k^G_{t+1}$'s contribution to
$\hat y_{t+1}$ itself.
Under \texttt{lump\_sum}, $\text{tax\_wedge}=0$ collapses all four
formulas to $\text{coef}_c=1-\Omega y_c$, $\text{coef}_k=-\Omega(y_k-1)$,
$\text{coef}_g=-\Omega y_g=0$, $\text{coef}_{kg}=-\Omega y_{kg}$.
\end{itemize}

\subsection{The capital-accumulation coefficients (L251--L254)}
\label{sec:capaccumsec}

\textbf{Derivation.} Log-linearizing $K_{t+1}=(1-\delta)K_t+I_t$ around the
steady state (using $I=\delta K$ there):
\eq{ \hat k_{t+1} = (1-\delta)\hat k_t+\delta\,\hat\imath_t. }
Log-linearizing the resource constraint $Y_t=C_t+I_t+G_{B,t}+I^G_t$ (using
$s_C+s_I+s_{GR}=1$, where $s_{GR}=s_{GB}+s_{IG}$ --- \emph{not} $s_G$,
since $TR$ does not appear in the resource constraint,
Section~\ref{sec:policybudget}) and solving for $\hat\imath_t$:
\eq{ \hat\imath_t = \frac{1}{s_I}\hat y_t-\frac{s_C}{s_I}\hat c_t-\frac{s_{GR}}{s_I}\hat g_t. }
Substituting $\hat y_t=y_k\hat k_t+y_{kg}\hat k^G_t+y_c\hat c_t+y_g\hat g_t$:
\eq{ \hat\imath_t = \frac{y_k}{s_I}\hat k_t+\frac{y_{kg}}{s_I}\hat k^G_t+\frac{y_c-s_C}{s_I}\hat c_t+\frac{y_g-s_{GR}}{s_I}\hat g_t, }
and substituting this into $\hat k_{t+1}=(1-\delta)\hat k_t+\delta\hat\imath_t$
gives exactly:

\begin{lstlisting}[firstnumber=251]
Phi_kk = (1.0 - delta) + delta * y_k / s_I
Phi_kc = delta * (y_c - s_C) / s_I
Phi_kg = delta * (y_g - s_GR) / s_I
Phi_k_kg = delta * y_kg / s_I
\end{lstlisting}
\begin{itemize}
\item[\textbf{L251}] $\Phi_{kk}=(1-\delta)+\delta y_k/s_I$ (unchanged in
form).
\item[\textbf{L252}] $\Phi_{kc}=\delta(y_c-s_C)/s_I$ (unchanged in form).
\item[\textbf{L253}] $\Phi_{kg}=\delta(y_g-s_{GR})/s_I$ --- \emph{note}
$s_{GR}$ here, not $s_G$: an increase in $G_B$ or $I^G$ (both counted in
$s_{GR}$) directly crowds out resources available for investment, but a
transfer $TR$ (part of $s_G$ but not $s_{GR}$) does not, since it is
returned to the household rather than spent on goods.
\item[\textbf{L254}] $\Phi_{k,kg}=\delta y_{kg}/s_I$ --- public capital
affects next period's private capital \emph{only} through its effect on
output $\hat y_t$ (via $y_{kg}$), with no direct ``$-s_{GR}$''-style
resource-crowding term, since $K^G$ is a stock, not a flow that competes
with $I$ for resources in the current period's identity.
\end{itemize}

\begin{lstlisting}[firstnumber=256]
return dict(y_k=y_k, y_kg=y_kg, y_c=y_c, y_g=y_g, s_GR=s_GR,
            coef_c=coef_c, coef_k=coef_k, coef_g=coef_g, coef_kg=coef_kg,
            Phi_kk=Phi_kk, Phi_kc=Phi_kc, Phi_kg=Phi_kg, Phi_k_kg=Phi_k_kg)

\item[\textbf{L256--L257}] Returns all twelve coefficients plus $s_{GR}$

\end{itemize}

\section{\texttt{\_kg\_hat\_path}: public capital's own law of motion (L261--L272)}
\label{sec:kghat}

\textbf{Derivation.} Log-linearizing $K^G_{t+1}=(1-\delta)K^G_t+I^G_t$
around the steady state (using $K^G=I^G/\delta$ there, i.e.\ $I^G=\delta
K^G$):
\eq{ \hat k^G_{t+1} = (1-\delta)\hat k^G_t+\delta\,\hat\imath^G_t. }
Because the app holds the composition fractions $f_{GB},f_{IG},f_{TR}$
fixed across a policy experiment (Section~\ref{sec:policybudget}), public
investment is always a constant fraction of total government purchases,
$I^G_t=f_{IG}\,G_t$, so its log-deviation is \emph{identical} to total
government purchases' log-deviation: $\hat\imath^G_t=\hat g_t$. Substituting,
\eq{ \hat k^G_{t+1} = (1-\delta)\hat k^G_t+\delta\,\hat g_t. \label{eq:kg-law} }
This is a remarkable simplification: $\hat k^G_t$'s own law of motion does
not depend on $\hat k_t$ or $\hat c_t$ at all --- it is driven
\emph{exogenously} by the (known, policy-chosen) government-spending path
$\{\hat g_t\}$. This is exactly why the model does not need a
$3\times3$ generalization of the Blanchard--Kahn eigendecomposition
(Section~\ref{sec:saddle} stays a $2\times2$ problem): $\hat k^G_t$ can be
solved on its own, in closed recursive form, and then simply \emph{fed
into} the $(\hat k,\hat c)$ system as one more known forcing term (via
$\Phi_{k,kg}$ and $\text{coef}_{kg}$, Section~\ref{sec:loglinear}).

\begin{lstlisting}[firstnumber=261]
def _kg_hat_path(delta: float, g_full: np.ndarray, kg0: float) -> np.ndarray:
    T = len(g_full)
    kg = np.zeros(T + 1)
    kg[0] = kg0
    g_ext = np.concatenate([g_full, [0.0]])
    for t in range(T):
        kg[t + 1] = (1.0 - delta) * kg[t] + delta * g_ext[t]
    return kg
\end{lstlisting}
\begin{itemize}
\item[\textbf{L261}] Signature: depreciation rate, the (already
zero-padded-by-the-caller-to-length-$T_{\text{sim}}$) government-spending
path, and the initial public-capital log-deviation $\hat k^G_0\equiv$
\texttt{kg0}. Returns $T+1$ values, $\hat k^G_0,\dots,\hat k^G_T$ ---
\emph{one more} than the input length, so that the Euler-equation forcing
term at the very last simulated period $t=T-1$ (which needs
$\hat k^G_{t+1}=\hat k^G_T$, one step beyond the $g$-path) is always
available (Section~\ref{sec:saddle} confirms this is exactly how the
extra period gets used).
\item[\textbf{L266}] Allocates a length-$(T+1)$ array and seeds
$\hat k^G_0=$ \texttt{kg0} --- the caller-supplied initial condition
(analogous to \texttt{k0} for private capital; see
Section~\ref{sec:expsec}'s discussion of how \texttt{kg0} is computed for
permanent vs.\ temporary experiments).
\item[\textbf{L269}] Appends a trailing zero to \texttt{g\_full}, exactly
as \texttt{\_solve\_saddle\_path} does, so that the recursion's last step
(computing $\hat k^G_T$ from $\hat k^G_{T-1}$ and $\hat g_{T-1}$) is
well-defined and consistent with the assumption that the shock has died
out by the end of the horizon.
\item[\textbf{L270--L271}] Implements \eqref{eq:kg-law} directly by simple
forward iteration --- safe here (unlike the $\hat k,\hat c$ system) because
this is a \emph{one}-variable, first-order, \emph{stable} recursion (its
own root is $1-\delta\in(0,1)$, since $0<\delta<1$), with no forward-looking
component to worry about blowing up.
\end{itemize}

\section{\texttt{\_solve\_saddle\_path}: the Blanchard--Kahn/KPR solution (L275--L336)}
\label{sec:saddle}

\begin{lstlisting}[firstnumber=275]
def _solve_saddle_path(Phi_kk: float, Phi_kc: float, Phi_kg: float, Phi_k_kg: float,
                        coef_c: float, coef_k: float, coef_g: float, coef_kg: float,
                        k0: float, g_full: np.ndarray, kg_full: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
\end{lstlisting}
\begin{itemize}
\item[\textbf{L275--L277}] Signature: the eight coefficients from
Section~\ref{sec:loglinear} that involve $\hat k$ or $\hat c$ (the
$y_k,y_{kg},y_c,y_g$ coefficients are not needed here --- they are only
used afterward, in \texttt{simulate\_transition}, to convert the solved
$(\hat k_t,\hat c_t)$ into $\hat y_t$), an initial capital log-deviation
$k_0$, the full-length government-spending path \texttt{g\_full}, and the
length-$(T+1)$ public-capital path \texttt{kg\_full} from
Section~\ref{sec:kghat}, supplied as a \emph{known} forcing input rather
than solved jointly. Returns the two log-deviation paths $\{\hat k_t\},\{\hat c_t\}$.
\end{itemize}

\textbf{Setting up a first-order forward system.} Equations
\eqref{eq:capaccum} and \eqref{eq:euler} together are one equation with a
\emph{predetermined} variable ($k$, whose value at $t$ was fixed by the
past) and one \emph{jump} variable ($c$, free to move on impact); $\hat
k^G_t$ is a third, purely exogenous input (Section~\ref{sec:kghat}). Solve
\eqref{eq:euler} for $\hat c_{t+1}$ using \eqref{eq:capaccum}'s expression
for $\hat k_{t+1}$:
\eq{
\hat c_{t+1} = \frac{1}{\text{coef}_c}\hat c_t-\frac{\text{coef}_k}{\text{coef}_c}\hat k_{t+1}-\frac{\text{coef}_g}{\text{coef}_c}\hat g_{t+1}-\frac{\text{coef}_{kg}}{\text{coef}_c}\hat k^G_{t+1}, \qquad
\hat k_{t+1}=\Phi_{kk}\hat k_t+\Phi_{kc}\hat c_t+\Phi_{kg}\hat g_t+\Phi_{k,kg}\hat k^G_t,
}
and substitute the second into the first to write both $\hat k_{t+1}$ and
$\hat c_{t+1}$ purely in terms of $(\hat k_t,\hat c_t)$ and the (now
two-part: $g$ and $k^G$) forcing path:
\eq{
\begin{pmatrix}\hat k_{t+1}\\ \hat c_{t+1}\end{pmatrix}
= \underbrace{\begin{pmatrix}\Phi_{kk} & \Phi_{kc}\\[2pt]
              -\dfrac{\text{coef}_k\Phi_{kk}}{\text{coef}_c} & \dfrac{1-\text{coef}_k\Phi_{kc}}{\text{coef}_c}
              \end{pmatrix}}_{\displaystyle M}
  \begin{pmatrix}\hat k_t\\ \hat c_t\end{pmatrix}
  +\begin{pmatrix}\Phi_{kg}\hat g_t+\Phi_{k,kg}\hat k^G_t\\[2pt]
                   -\dfrac{\text{coef}_k(\Phi_{kg}\hat g_t+\Phi_{k,kg}\hat k^G_t)}{\text{coef}_c}-\dfrac{\text{coef}_g}{\text{coef}_c}\hat g_{t+1}-\dfrac{\text{coef}_{kg}}{\text{coef}_c}\hat k^G_{t+1}\end{pmatrix}.
  \label{eq:M-system}
}
Notice $M$ itself is completely unchanged by the addition of public
capital --- it is still built \emph{only} from $\Phi_{kk},\Phi_{kc},
\text{coef}_k,\text{coef}_c$, exactly as in the baseline model. Public
capital enters purely through the additive forcing vector, which is why
the eigendecomposition below stays $2\times2$.

\begin{lstlisting}[firstnumber=297]
M = np.array([[Phi_kk, Phi_kc],
              [-coef_k * Phi_kk / coef_c, (1.0 - coef_k * Phi_kc) / coef_c]])
\end{lstlisting}
\begin{itemize}
\item[\textbf{L297--L298}] Builds $M$ exactly as in \eqref{eq:M-system}.
\end{itemize}

\textbf{Diagonalizing $M$.} Since $M$ is $2\times2$ with real entries in
this model's calibrated range, it has (generically) two real eigenvalues
$\lambda_s,\lambda_u$ with eigenvectors forming the columns of a matrix
$V$, so $M=V\,\text{diag}(\lambda_s,\lambda_u)\,V^{-1}$. Saddle-path
stability (King, Plosser \& Rebelo 1988; the Blanchard--Kahn condition for
one predetermined and one jump variable) requires \emph{exactly one} root
inside the unit circle ($|\lambda_s|<1$, associated with the predetermined
$\hat k$) and one outside ($|\lambda_u|>1$, associated with the jump
variable $\hat c$).

\begin{lstlisting}[firstnumber=299]
vals, vecs = np.linalg.eig(M)
if np.max(np.abs(vals.imag)) > 1e-8:
    raise RuntimeError("Complex eigenvalues encountered; parameters imply oscillatory "
                        "dynamics not supported by this simplified solver.")
vals = vals.real
vecs = vecs.real
stable_idx = int(np.argmin(np.abs(vals)))
unstable_idx = 1 - stable_idx
lam_s, lam_u = vals[stable_idx], vals[unstable_idx]
if not (abs(lam_s) < 1.0 < abs(lam_u)):
    raise RuntimeError("Model is not saddle-path stable for these parameters "
                        "(need exactly one root inside and one outside the unit circle).")
V = vecs[:, [stable_idx, unstable_idx]]
Vinv = np.linalg.inv(V)
\end{lstlisting}
\begin{itemize}
\item[\textbf{L299}] NumPy's general eigenvalue solver.
\item[\textbf{L300--L303}] Guards against complex eigenvalues (damped-
oscillatory dynamics, outside this solver's scope) and discards
numerically negligible imaginary parts.
\item[\textbf{L305}] Identifies the stable eigenvalue as whichever has the
smaller absolute value.
\item[\textbf{L306}] The other index is the unstable one.
\item[\textbf{L307}] $\lambda_s,\lambda_u$ read off.
\item[\textbf{L308--L310}] Verifies true saddle-path stability; raises
otherwise.
\item[\textbf{L311}] Reorders the eigenvector matrix's columns so column
$0$ is stable, column $1$ unstable.
\item[\textbf{L312}] Inverts $V$, needed to rotate $(\hat k_t,\hat c_t)$
into the eigenbasis $\zeta_t\equiv V^{-1}(\hat k_t,\hat c_t)^\top$, in
which the system decouples: $\zeta_{1,t+1}=\lambda_s\zeta_{1,t}+n_{t,0}$,
$\zeta_{2,t+1}=\lambda_u\zeta_{2,t}+n_{t,1}$, where $(n_{t,0},n_{t,1})^\top$
is the forcing term from \eqref{eq:M-system} (now including both the
$g$-driven and $k^G$-driven pieces), rotated into the same eigenbasis.
\end{itemize}

\begin{lstlisting}[firstnumber=314]
T = len(g_full)

      - coef_kg * kg_next) / coef_c
N = np.stack([Nk, Nc], axis=1)
n = N @ Vinv.T  # forcing rotated into the eigen-basis: n[:,0]=stable comp., n[:,1]=unstable
\end{lstlisting}
\begin{itemize}
\item[\textbf{L314}] $T$, the simulation horizon.
\item[\textbf{L315}] Appends a trailing zero to \texttt{g\_full}, so
\texttt{g\_ext[T]} (needed as $\hat g_T$, one period past the horizon) is
well-defined and consistent with the shock having died out.
\item[\textbf{L316--L317}] Slices the length-$(T+1)$ \texttt{kg\_full}

\item[\textbf{L318}] $N_k[t]=\Phi_{kg}\hat g_t+\Phi_{k,kg}\hat k^G_t$ for

\eqref{eq:M-system}, now with both the government-spending and
public-capital pieces.
\item[\textbf{L319--L320}] $N_c[t]=-\dfrac{\text{coef}_k(\Phi_{kg}\hat
g_t+\Phi_{k,kg}\hat k^G_t)}{\text{coef}_c}-\dfrac{\text{coef}_g}{\text{coef}_c}\hat
g_{t+1}-\dfrac{\text{coef}_{kg}}{\text{coef}_c}\hat k^G_{t+1}$ --- the
$\hat c_{t+1}$ row's forcing term, using the contemporaneous $\hat g_t,\hat

one-period-ahead $\hat g_{t+1},\hat k^G_{t+1}$ directly, exactly as
\eqref{eq:M-system} requires.
\item[\textbf{L321}] Stacks $N_k,N_c$ into a $T\times2$ array.
\item[\textbf{L322}] Rotates every row into the eigenbasis via
\texttt{N @ Vinv.T}.
\end{itemize}

\textbf{Solving the unstable (jump) component backward.} Exactly as in the
baseline model: iterating $\zeta_{2,t+1}=\lambda_u\zeta_{2,t}+n_{t,1}$
forward would blow up geometrically since $|\lambda_u|>1$. Instead, impose
the no-bubble condition $\zeta_{2,t}\to0$ as the forcing dies out and solve
backward, giving the discounted present value of all remaining forcing
(now including the $\hat k^G$-driven piece baked into $n_{t,1}$):
\eq{ \zeta_{2,t} = -\sum_{j=0}^{T-1-t}\frac{n_{t+j,1}}{\lambda_u^{\,j+1}}. \label{eq:zeta2} }

\begin{lstlisting}[firstnumber=324]
zeta2 = np.zeros(T)
running = 0.0
for t in range(T - 1, -1, -1):
    running = (n[t, 1] + running) / lam_u
    zeta2[t] = -running
\end{lstlisting}
\begin{itemize}
\item[\textbf{L324--L328}] Implements \eqref{eq:zeta2} by a single
backward pass, unchanged in structure from the baseline model (only the
\emph{contents} of $n_{t,1}$ differ, now including the public-capital
forcing).
\end{itemize}

\textbf{Solving the stable (predetermined) component forward.} Since
$|\lambda_s|<1$, iterating $\zeta_{1,t+1}=\lambda_s\zeta_{1,t}+n_{t,0}$
forward from $t=0$ is numerically safe. The starting value $\zeta_{1,0}$
is pinned by the one true initial condition, $\hat k_0=k_0$:
\eq{ \zeta_{1,0} = \frac{k_0-V_{01}\,\zeta_{2,0}}{V_{00}}. \label{eq:zeta1-0} }

\begin{lstlisting}[firstnumber=330]

return z[0, :], z[1, :]
\end{lstlisting}
\begin{itemize}

forward recursion for $\zeta_{1,t}$, unchanged in structure from the
baseline model.
\item[\textbf{L335}] Rotates back out of the eigenbasis, $\begin{pmatrix}\hat
k_t\\\hat c_t\end{pmatrix}=V\zeta_t$, for every $t$ at once via
\texttt{V @ np.vstack([zeta1, zeta2])}.
\item[\textbf{L336}] Returns row $0$ ($\{\hat k_t\}$) and row $1$
($\{\hat c_t\}$).
\end{itemize}

\section{Table 4 replication: \texttt{public\_investment\_long\_run} and \texttt{\_public\_capital\_output} (L482--L534)}
\label{sec:table4}

This section powers the app's ``Productive public investment'' panel,
answering: as public capital's productivity parameter $\theta_G$ ranges
over a grid, how does a marginal dollar of public investment $I^G$ affect
long-run output, consumption, and investment --- holding the public-
investment \emph{share} of output, $s_{IG}=I^G/Y$, fixed?

\begin{lstlisting}[firstnumber=482]
def public_investment_long_run(theta_N: float, delta: float, r: float, A: float,
                                 s_GB: float, theta_L: float, distortionary: bool,
                                 theta_G_grid: np.ndarray, s_IG: float = 0.05) -> "dict[str, np.ndarray]":
    ss0 = steady_state(theta_N, delta, r, A, 0.0, s_GB, s_IG, 0.0, distortionary, theta_L)
    theta_K = ss0.theta_K

    direct = theta_G_grid.copy()
    k_adj = theta_G_grid / (1.0 - theta_K)
\end{lstlisting}
\begin{itemize}
\item[\textbf{L482--L484}] Signature: basic government purchases, the
already-calibrated $\theta_L$ (calibrated once, at $\theta_G=0$, and held
fixed across the whole grid --- so preferences do not change as $\theta_G$
is swept, only the technology does), the financing rule, and a grid of
$\theta_G$ values to evaluate, at a fixed public-investment share
\texttt{s\_IG}.
\item[\textbf{L495}] Builds a reference steady state at $\theta_G=0$
(needed only to read off $\theta_K$, which does not depend on $\theta_G$
or $s_{IG}$ at all --- this is really just a convenience way to get
$\theta_K=1-\theta_N$ alongside a sanity-checked, fully-populated
\texttt{SteadyState} object).
\item[\textbf{L498}] \textbf{Column (i), the ``direct'' effect}: holding
private capital $K$ and labor $N$ fixed, a marginal increase in $I^G$
raises $Y$ one-for-one with its \emph{direct} productivity contribution,
$dY/dI^G=\partial Y/\partial K^G\cdot dK^G/dI^G=(\theta_G Y/K^G)\cdot(1/\delta)$
evaluated where $I^G=\delta K^G$ simplifies to exactly $\theta_G$ --- i.e.\
the elasticity parameter itself, unmodified. This is the smallest,
most conservative estimate of the effect, ignoring all equilibrium
responses.
\item[\textbf{L499}] \textbf{Column (ii), private capital adjusts (labor
fixed)}: a standard result for Cobb--Douglas production with two capital-like
inputs is that if $K$ is allowed to re-optimize (via the capital-Euler
condition) in response to $K^G$'s productivity boost, but $N$ is held
fixed, the total multiplier is scaled up by $1/(1-\theta_K)$ --- the same
algebra as a standard capital-deepening amplification factor.
\end{itemize}

\begin{lstlisting}[firstnumber=501]
both = np.zeros_like(theta_G_grid)
dC = np.zeros_like(theta_G_grid)
dI = np.zeros_like(theta_G_grid)
for idx, theta_G in enumerate(theta_G_grid):
    h = 1e-4
    m1 = _public_capital_output(theta_N, theta_K, delta, r, A, s_GB, theta_L, distortionary,
                                 theta_G, s_IG - h)
    m2 = _public_capital_output(theta_N, theta_K, delta, r, A, s_GB, theta_L, distortionary,
                                 theta_G, s_IG + h)
    both[idx] = (m2["Y"] - m1["Y"]) / (m2["IG"] - m1["IG"])
    dC[idx] = (m2["C"] - m1["C"]) / (m2["IG"] - m1["IG"])
    dI[idx] = (m2["I"] - m1["I"]) / (m2["IG"] - m1["IG"])

return dict(theta_G=theta_G_grid, direct=direct, k_adj=k_adj, both=both, dC=dC, dI=dI)
\end{lstlisting}
\begin{itemize}
\item[\textbf{L504--L512}] \textbf{Column (iii), full general equilibrium}
(and the analogous $\Delta C/\Delta I^G$ and $\Delta I/\Delta I^G$, shown
alongside it in the app's table): rather than deriving a further
closed-form elasticity (both private capital \emph{and} labor adjust,
which does not reduce to a single clean multiplicative factor the way
columns (i)--(ii) do), the code takes a \textbf{numerical derivative}: it
computes the exact nonlinear steady state at $s_{IG}\mp h$ for a tiny
$h=10^{-4}$, using $\theta_L$ and $\theta_G$ held fixed, and forms the
centered finite difference $\Delta Y/\Delta I^G\approx(Y(s_{IG}+h)-Y(s_{IG}-h))/(I^G(s_{IG}+h)-I^G(s_{IG}-h))$
--- and likewise for $C$ and $I$. This is exact to the precision of the
finite-difference step, and, being built from two calls to the same
closed-form \texttt{\_public\_capital\_output} steady-state solver, never
suffers a root-finder's convergence failure.
\item[\textbf{L514}] Returns all five series (\texttt{direct}, \texttt{k\_adj},
\texttt{both}, \texttt{dC}, \texttt{dI}) keyed by name, plus the grid
itself, for the app to tabulate.
\end{itemize}

\begin{lstlisting}[firstnumber=517]
def _public_capital_output(theta_N, theta_K, delta, r, A, s_GB, theta_L, distortionary, theta_G, s_IG):
    tau = s_GB + s_IG
    supply = _supply_side_impl(theta_N, delta, r, A, tau, theta_G, s_IG, distortionary)
    s_I = supply["s_I"]
    s_C = 1.0 - s_I - s_GB - s_IG
    if s_C <= 0:
        s_C = 1e-6
    wedge = supply["wedge"]
    N = wedge * theta_N / (theta_L * s_C + wedge * theta_N)
    Y = supply["alpha"] * N
    K = supply["kappa"] * N
    KG = supply["KG"] * N
    C = s_C * Y
    I = s_I * Y
    IG = s_IG * Y
    return dict(Y=Y, C=C, I=I, IG=IG, K=K, KG=KG, N=N)
\end{lstlisting}
\begin{itemize}
\item[\textbf{L517}] Signature: a lean, single-purpose re-implementation of
the steady-state solve (deliberately \emph{not} routed through the general
\texttt{steady\_state} function, since this is called $2\times$ per grid
point $\times$ up to $10$ grid points every time the app re-renders, and
avoiding \texttt{SteadyState} object construction overhead keeps the
Table~4 panel responsive), specialized to this cross-section: no
transfers ($TR\equiv0$ here, so $\tau=s_{GB}+s_{IG}$ exactly, matching the
docstring's tax-rate identity with $s_{TR}=0$).
\item[\textbf{L521}] The tax rate for this cross-section.
\item[\textbf{L522}] Calls Section~\ref{sec:supply}'s price system.
\item[\textbf{L524--L526}] $s_C=1-s_I-s_{GB}-s_{IG}$, floored at a tiny
positive number ($10^{-6}$) rather than raising, so that the finite-
difference step $h=10^{-4}$ in \texttt{public\_investment\_long\_run}
never crashes even if one of the two perturbed points is numerically at
the edge of feasibility --- a deliberate robustness trade-off appropriate
for a function used only inside a numerical-derivative loop, not exposed
directly to the app's user-facing error handling.
\item[\textbf{L528}] $N=\omega\theta_N/(\theta_L s_C+\omega\theta_N)$,
identical in form to \texttt{steady\_state}'s L168.
\item[\textbf{L529--L534}] Computes and returns $Y,K,K^G,C,I,I^G,N$
exactly as \texttt{steady\_state} would, just without constructing a full
\texttt{SteadyState} dataclass.
\end{itemize}
